# SHET BURGER — Experiencia web oficial

Landing comercial construida con React y Vite. La portada presenta la hamburguesa con las siete capas fotográficas reales y la sección de storytelling la mantiene ensamblada sobre un plato, sin animaciones invasivas.

El catálogo vive en `src/data.js`, separado de la presentación y preparado para sustituirse por una fuente de datos de Supabase. Los nombres, descripciones y precios provienen del menú oficial incluido en el proyecto.

## Desarrollo

```bash
npm install
npm run dev
```

Para producción: `npm run build` y luego `npm run preview`.
